# Projeto Básico de Análise de Vendas com SQL

Este projeto contem a pratica com SQL usando dados de vendas.

Fiz consultas para responder perguntas comuns, como:  
- Quais produtos mais vendem?  
- Quais clientes gastaram mais?  
- Tem produto vencido sendo vendido?  
- Quem voltou a comprar?  

Também criei views para facilitar essas análises.

---

## Dados usados

Para simular os dados, usei uma ferramenta chamada **Mockaroo**, que gera dados falsos parecidos com os reais.  
Com isso, pude criar a tabela e popular com inserts para testar as queries.

---

## Uso de Inteligência Artificial (IA)

Usei a IA para ajudar a criar cenários e perguntas reais de negócio, como se fosse uma gerente comercial pedindo informações.  
Isso ajudou a pensar melhor no que precisava analisar e a praticar SQL respondendo essas perguntas.

---

## Como usar

Basta rodar os arquivos SQL na sua ferramenta de banco de dados após realizar a criação da tabela e gerar os inserts.
